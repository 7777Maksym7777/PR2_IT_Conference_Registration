# Практична робота №2 — Форма реєстрації на IT-конференцію

## Варіант
№2 — Форма реєстрації на IT-конференцію / Workshop.

## Мета
Закріпити навички побудови адаптивної форми за допомогою CSS Flexbox, семантичної HTML5-розмітки, нативної валідації та доступності.

## Файли проєкту
- `index.html` — семантична структура форми та медіаблоку.
- `styles.css` — Flexbox, дизайн-токени, адаптивність і стани полів.
- `script.js` — перевірка файлу та демонстраційне підтвердження реєстрації.

## Реалізовано
Поля імені, email і посади; вибір секції; завантаження PNG/JPG/PDF до 5 МБ; обов'язкова згода з правилами; адаптивний банер у `figure` з `figcaption`; нативна HTML5-валідація (`required`, `pattern`, `minlength`, `maxlength`, `type=email`); Flexbox; `:hover`, `:focus-visible`, `:invalid`; повідомлення результату через `output` та `aria-live`.

## Запуск
Відкрийте `index.html` у браузері. Сервер і сторонні бібліотеки не потрібні. Форма демонстраційна: дані перевіряються у браузері, але не надсилаються на сервер.

## Інструкція для Figma UI Kit
1. Створіть Figma-файл `PR2 — Conference Registration` і сторінку `UI Kit`.
2. Додайте Color Styles/Variables: Background `#F4F7FB`, Surface `#FFFFFF`, Text `#172033`, Accent `#5B4BDB`, Error `#B42318`.
3. Створіть текстові стилі Title (28 px, Bold) та Body (16 px, Regular).
4. Створіть компонент Text Field з вертикальним Auto Layout: Label, поле вводу та Hint/Error. Поле: висота 48 px, padding 12 px, radius 10 px.
5. Створіть Variants `State=Default` та `State=Focus`. Для Focus змініть обведення на Accent і додайте зовнішній контур. За бажанням додайте Error.
6. Створіть компонент Select Field на основі Text Field зі стрілкою.
7. Створіть Upload Field: горизонтальний Auto Layout з іконкою, текстовою групою та контролом завантаження.
8. Створіть кнопку Submit висотою 50 px, radius 11 px, Accent background і білий текст.
9. Створіть Desktop Frame 1440 px. Головний Auto Layout — горизонтальний, gap 56 px, padding 48 px. Усередині розмістіть форму та медіакартку.
10. Форму зберіть вертикальним Auto Layout із gap 18 px. Кожне поле — окрема група.
11. Медіакартку створіть із банером, назвою події та описом. Для ілюстрації використайте градієнт і декоративні еліпси.
12. Створіть Mobile Frame 375 px. Головний Auto Layout зробіть вертикальним, ширину блоків — Fill container.
13. Переконайтеся, що всі відступи створені через Auto Layout, а не ручне позиціювання.

## Тестування
1. Натискати Tab і Shift+Tab — фокус має послідовно переходити між полями та кнопкою.
2. Надіслати порожню форму — браузер має показати нативні повідомлення валідації.
3. Ввести некоректний email — форма не повинна пройти перевірку.
4. Вибрати файл неправильного формату або понад 5 МБ — має з'явитися повідомлення.
5. Заповнити обов'язкові поля, погодитися з правилами та натиснути кнопку — має з'явитися підтвердження.
6. Змінити ширину браузера до 375 px — блоки мають перейти у вертикальне компонування.

## W3C Nu HTML Checker
Перед здачею вставте `index.html` у https://validator.w3.org/nu/#textarea і натисніть Check. Не зазначайте у звіті, що валідатор пройдено, доки фактично не виконаєте перевірку.
